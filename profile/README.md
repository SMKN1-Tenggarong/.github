## Overview: Kolaborasi Digital Lintas Generasi

Organisasi ini adalah Hub Inovasi Digital resmi siswa SMK Negeri 1 Tenggarong. Diinisiasi oleh [Luvi Aprilyansyah Gabriel](https://github.com/leapwithluvi), ekosistem ini dirancang untuk:
- Menghubungkan siswa RPL (PPLG) dan TKJ (TJKT) dalam satu workflow.
- Preservasi Ilmu: Memastikan project sekolah tidak hilang saat siswa lulus.
- Standar Industri: Membiasakan siswa dengan tools profesional (Git, CI/CD, Agile).

<br/>

## Kontribusi Siswa

Bergabunglah dalam perjalanan digital ini!
1. Fork & Clone: Ambil project yang ingin kamu kembangkan.
2. Feature Branch: Buat branch baru untuk setiap fitur/perbaikan.
3. Pull Request: Ajukan perubahanmu untuk di-review oleh pembimbing/senior.
